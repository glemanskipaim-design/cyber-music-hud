## MINOR

1. **media.cpp:186-190 — a capa some depois de pausar e retomar a mesma faixa.**
   A capa só é carregada quando `show` é true. Ao pausar, a chave vira vazia
   e `current_` vira nullopt. Ao retomar, a chave já é a anunciada (sem
   anúncio), mas difere de `resolvedKey`, então `current_` é regravado
   **sem** `art`. "Mostrar agora" passa a abrir o painel estreito, sem capa,
   para a mesma música que antes tinha capa. O comentário da linha 187
    ("Mostrar agora também a reaproveita") só vale até a primeira pausa.
   Correção: guardar a última capa por chave.
   ```cpp
   std::wstring artKey; std::vector<uint8_t> art;   // fora do laço
   ...
   if (show) { art = LoadArt(playing->thumbnail); artKey = key; }
   if (playing && key == artKey) playing->track.art = art;
   ```

2. **hud.cpp:354-358 — `CreateBitmap` que falha é repetido a cada frame.**
   O comentário diz "Sem capa se falhar", mas a guarda
   `!art_ && !track_.art.empty()` continua verdadeira e o CreateBitmap é
   chamado de novo ~30x/s até o HUD sumir. Correção: registrar a falha.
   ```cpp
   if (FAILED(target_->CreateBitmap(...))) track_.art.clear();  // não tenta de novo
   ```
   Isso também tira a moldura vazia. Se a moldura for intencional, use um
   `bool artFailed_` resetado em Show.

3. **logic.h:145-147 vs hud.cpp:53/55/60 — a paleta ficou duplicada em duas representações.**
   `kDark`/`kCyan`/`kHot` (BGR 0..255 em TintArt) são cópias à mão de
   `kPanel`/`kAccent`/`kBarHot` (D2D 0..1 em hud.cpp). Mudar o tema no HUD
   deixa a capa no tom antigo, sem nenhum aviso. Correção: definir a paleta
   uma vez em logic.h (ex. `struct Rgb { float r, g, b; }`, com
   `inline constexpr Rgb kPaletteCyan = {0.0f, 0.898f, 1.0f};`), fazer hud.cpp
   montar os `D2D1_COLOR_F` a partir dela e TintArt multiplicar por 255.

4. **hud.cpp:267 e media.cpp:69 — o tamanho em bytes da capa é calculado à mão em dois lugares.**
   `static_cast<size_t>(kArtPixels) * kArtPixels * 4` aparece no produtor e
   no validador (e `kArtPixels * 4` como stride em media.cpp:70 e
   hud.cpp:358). Correção: em logic.h,
   ```cpp
   inline constexpr UINT32 kArtStride = kArtPixels * 4;
   inline constexpr size_t kArtBytes = static_cast<size_t>(kArtStride) * kArtPixels;
   ```

5. **hud.cpp:270-271 — `+ 1.0f` / `- 1.0f` deixa a geometria difícil de ler.**
   `playX_ = kPadX + 1 + art; textX_ = playX_ - 1 + kPlayToText` só
   significa "texto a kPlayToText da coluna de conteúdo, ícone 1 DIP para a
   direita". Correção:
   ```cpp
   const float contentX = kPadX + (hasArt ? kArtSize + kArtGap : 0.0f);
   playX_ = contentX + kPlayIconNudge;   // constexpr float kPlayIconNudge = 1.0f;
   textX_ = contentX + kPlayToText;
   ```
